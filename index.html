Política de privacidad – WebGuard

Última actualización: 14 de noviembre de 2026

WebGuard es una app que bloquea sitios web, páginas y palabras clave elegidos por el usuario cuando se abren en Google Chrome y otros navegadores compatibles.

Uso de la API de Servicios de Accesibilidad

WebGuard usa la API AccessibilityService de Android únicamente para:

  1. Leer el texto de la barra de direcciones (URL) de los navegadores compatibles (Chrome, Chrome Beta/Dev/Canary, Brave, Edge, Kiwi, Vivaldi, Opera, Samsung Internet y Firefox).
  2. Comparar esa dirección con la lista de bloqueo que el usuario configuró.
  3. Si coincide, cerrar esa página (navegar a una página en blanco o cerrar la pestaña personalizada) y mostrar una pantalla de bloqueo.

WebGuard no lee el contenido de las páginas web, no lee otras apps, no registra lo que escribís y no guarda tu historial de navegación.

Datos que se almacenan

  • Tu lista de bloqueo (dominios, direcciones y palabras clave que agregaste).
  • El estado del bloqueo (activado/pausado) y un contador de bloqueos.

Estos datos se guardan solo en tu dispositivo. Si tenés activada la copia de seguridad de Android, pueden incluirse en la copia de seguridad cifrada de tu cuenta de Google, gestionada por Android.

Datos que se comparten

Ninguno. WebGuard no tiene acceso a Internet, no usa analíticas, publicidad ni SDKs de terceros, y no envía ningún dato fuera del dispositivo.

Control del usuario

Podés desactivar el servicio en cualquier momento desde Ajustes → Accesibilidad → WebGuard, pausar el bloqueo desde la app, o desinstalarla, lo que elimina todos sus datos.

Privacy Policy – WebGuard (English)

WebGuard uses Android’s Accessibility Service API only to read the address-bar URL of supported browsers, compare it with the block list the user configured, and, on a match, close that page and show a block screen. It does not read page content or other apps, does not log keystrokes, and does not store browsing history. The block list is stored only on the device. WebGuard has no internet permission, no analytics, no ads and no third-party SDKs, and shares no data. Users can turn the service off in Settings → Accessibility, or uninstall the app to delete all its data.
